## 1. Обзор проекта

**TimeHub-Portal** — учебный SPA-портал для студента. Изначально создан для Газпром колледжа Волгограда (группа 26 АТП-2Бо), но теперь позиционируется как **универсальная платформа для любого учебного заведения**. Любой студент может собрать свое расписание в Конструкторе, отправить его в Telegram-группу, и админ добавит его на сайт. **Важно:** авто-парсинга с сайта колледжа нет, всё держится на энтузиастах-волонтерах!

### 1.1. Функционал
- **Расписание пар** с учётом чётной/нечётной недели и замен.
- **Таймер** до конца/начала пары с адаптивным полноэкранным режимом. **На перемене показывает название, кабинет и номер следующей пары.**
- **Погода** в Волгограде с советами по одежде (можно выбрать API: Open-Meteo или wttr.in).
- **Заметки + чек-лист** с синхронизацией в Telegram CloudStorage и умным авто-ресайзом.
- **Стрик (огонёк)** — счётчик дней подряд с визуальной эволюцией и жесткой логикой сгорания (36 часов на спасение, 48 часов — смерть).
- **Справочник** (библиотеки, консультации преподавателей, калькулятор оценок).
- **12+ тем оформления** (включая Matrix и Nothing).
- **4 стиля интерфейса (UI Styles)**: Стекло (по умолчанию), Терминал, Брутализм, Nothing. Стили меняют только форму, границы и тени, **не перебивая выбранную цветовую тему и шрифт**.
- **Офлайн-режим** через Service Worker, установка как PWA и Telegram Mini App.
- **Конструктор** с 3 режимами: Расписания (`.js`), Замены (`data.json`), Консультации (`consultations.js`).
- **7 стилей плашки дней недели**: Веер, Минимализм, Капсула, Сегменты, Свайп + Точки, Сбоку (Dock), Светодиоды (LED).
- **Свайпы**: горизонтальный свайп по расписанию (для стиля «Точки»), горизонтальный свайп по полосе недель (включается в настройках).
- **7 анимаций смены дней**: Снизу, Слева, Затухание, Масштаб, Матовое, Пружина, Глитч (CRT).
- **Микроанимации нажатия** (`:active`) на всех кнопках, **плавный скролл** (`scroll-behavior: smooth`).
- **Адаптивная верстка** под узкие экраны (от 320px).
- **Лицензия CC BY-NC 4.0**.
- **Режим отладки (DANGER ZONE)**: скрытая панель разработчика (5 кликов по версии).

### 1.2. Технологический стек
- Чистый **Vanilla JS (ES6 Modules)**. Запрещено использовать React, Vue, jQuery, TypeScript или сборщики (Webpack/Vite).
- **HTML5 + CSS3** (CSS-переменные, Grid, Flexbox, анимации, медиа-запросы).
- **Хостинг:** GitHub Pages (чистая статика, без бэкенда).

- **Хранение:** `localStorage` (локальные настройки) + `Telegram CloudStorage` (настройки, заметки, чек-лист, стрик).

## 2. Быстрый старт

### 2.1. Локальный запуск
1. Открыть папку в VS Code / VSCodium.
2. Установить расширение **Live Server**.
3. ПКМ по `index.html` → **Open with Live Server** (порт 5500).
4. Для Конструктора: ПКМ по `builder.html` → **Open with Live Server**.
5. Открыть в браузере `http://127.0.0.1:5500/index.html`.

### 2.2. Деплой на GitHub Pages
```bash
git add .
git commit -m "описание изменений"
git push origin master
```

**Важно про Git-хук:** В проекте настроен `.git/hooks/pre-commit`, который автоматически меняет `CACHE_NAME` в `sw.js` на текущий timestamp (`timehub-v<unixtime>`). Это сбрасывает кэш у пользователей при каждом пуше. Пользователю не нужно менять версию вручную. Хук также делает `git add sw.js`, чтобы изменённый файл попал в коммит.

### 2.3. Service Worker и авто-обновление
`pwa.js` использует `updateViaCache: 'none'` — браузер всегда проверяет `sw.js` на сервере. Каждые 60 секунд вызывается `registration.update()`. При активации нового воркера страница автоматически перезагружается через событие `controllerchange` (флаг `refreshing` предотвращает зацикливание).

### 2.4. Где смотреть результат
- После `git push` подождать 1-2 минуты — GitHub Pages пересоберёт сайт.
- В Telegram: закрыть и открыть мини-апп заново, чтобы подтянулся новый Service Worker.
- Локально: обновить страницу (Ctrl+F5 или Ctrl+Shift+R).

## 4. Ключевые архитектурные изменения (Версия 1.9+)

### 4.1. 🚨 Система замен переведена на JSON и работает для ЛЮБОГО дня
**ВНИМАНИЕ:** Файла `data/substitutions/index.js` больше НЕТ.
Все замены теперь хранятся в **`data/substitutions/data.json`**.
- Ключ верхнего уровня — дата `YYYY-MM-DD`.
- Ключ второго — группа (кириллица).
- Ключ третьего — номер пары (строка, например `"4"`).
- Если `subject` пустой (`""`) — пара удаляется.

**⚠️ Главная фича `data-manager.js`:** Замены применяются для **любого выбранного дня**, а не только для сегодняшнего!
- Функция `getDateForDay(week, day)` берет `SEMESTER_START_DATE` и прибавляет к нему `(week - 1) * 7 + (day - 1)` дней.
- Получается точная дата (например, 2-я неделя, Вторник = 3 ноября). По этой дате ищутся замены в `data.json`.
- Поэтому, если ты листаешь недели или меняешь дни, замены будут подтягиваться корректно (если они есть на эти даты).

**Слияние замен в Билдере:** При генерации новых замен скрипт скачивает текущий `data.json` через `fetch()`, удаляет старые даты (меньше сегодняшней), объединяет с новыми и выдает готовый файл. Билдер также сравнивает введенные данные с базовым расписанием и выдает **только отличия** (диффы).

### 4.2. ☁️ Синхронизация настроек с облаком
- Все настройки (`timehub_settings`) дублируются в Telegram CloudStorage.
- **Base64-обои НЕ синхронизируются** (лимит 4096 символов).
- При загрузке приоритет у `localStorage`. Если он пуст (Telegram Desktop чистит кэш) — вызывается `restoreSettingsFromCloud()`.
- В `main.js` есть подписка `state.on('change:settings', ...)` с защитой от рекурсии (сравнение `JSON.stringify` без `_updatedAt`).

### 4.3. 🛠 Обновленный Конструктор (`builder.js`)
- Имеет **ТРИ режима**:
  - `schedule` — генерация расписания группы (`.js`).
  - `substitution` — генерация замен (`.json`).
  - `consultation` — генерация графика консультаций (`consultations.js`).
- **Структура `state`** сохраняется в `localStorage` под ключом `timehub_builder_state`.
- **Транслитерация:** `transliterate()` переводит `26 АТП-2Бо` → `26ATP-2Bo`.
- **Автоподстановка:** при выборе предмета поля «Кабинет» и «Преподаватель» заполняются автоматически (с зеленой подсветкой `.autofilled`). Работает во ВСЕХ трех режимах.
- **Консультации:** При генерации скачивает текущий `data/consultations.js` через `import()`, объединяет данные (обновляя существующие по связке `teacher` + `day` + `afterPair`) и генерирует JS-файл с красивыми комментариями.
- **Ссылка на Telegram-группу:** в модалке генерации есть кнопка перехода в группу.
- **Защита от ошибок:** функция `generateCode()` обернута в `try/catch`. Если что-то идет не так, выскакивает `alert` с текстом ошибки.

### 4.4. 📱 QR-код и Поделиться (`ui/settings.js`)
- Внутри Telegram генерирует QR на короткую ссылку бота. В браузере — на GitHub Pages.
- Использует `qr-code-styling@1.5.0`.
- Цвет QR подстраивается под тему через `ensureDarkEnough()`.

### 4.5. 🔥 Стрик (Огонек) и Шапка (`state.js` + `ui/header.js`)
- **Логика сгорания:** 
  - Разница < 36 часов: Огонь жив, серия растет.
  - Разница 36-48 часов: Статус `dying` (серый). Появляется кнопка «Спасти огонь» (`reviveStreak`).
  - Разница > 48 часов: Статус `dead` (полностью погас). Появляется кнопка «Начать заново» (`resetStreak`).
- **`ui/header.js`:** меню огонька показывает мотивационный текст («Зайди завтра...») и кнопки спасения/сброса.

### 4.6. 🌤 Погода кнопками и API (`ui/settings.js` + `ui/controls.js`)

- Поддерживаются API: `open-meteo` и `wttr-in`. Запросы к ним не кэшируются в `sw.js`.

### 4.7. 🧩 Скелетоны при загрузке

**Проблема:** Старая модалка настроек была длинной «простыней», в которой сложно найти нужный пункт.
**Решение (`ui/settings.js` + `style.css`):**
- Настройки разбиты на 4 логические группы-спойлера: **Оформление**, **Обои**, **Интерфейс**, **Приложение**.

### 4.16. 🔘 7 Стилей переключателя дней (`radial.css` + `ui/radial-day-picker.js`)
Теперь доступно 7 стилей (выбираются в настройках):
1. **Веер (radial)**: Кнопки вылетают из центра по математически рассчитанным координатам `X` и `Y` (через `--x` и `--y`), образуя идеальную полуокружность.
2. **Минимализм (minimal)**: Плавный ползунок (glider) под активным днем.
3. **Капсула (capsule)**: Активный день разворачивается в полную плашку с названием дня, остальные сжаты в кружочки.
4. **Сегменты (segmented)**: iOS-стиль с прямоугольным ползунком. Идеально для темы Nothing (прямые углы).
5. **Свайп + Точки (swipe)**: Внизу только 5 точек. Само расписание можно свайпать влево-вправо для смены дня (через `touchstart`/`touchend` на документе с проверкой на горизонтальность).
6. **Сбоку / Dock (vertical)**: Вертикальный столбик кружочков справа по центру экрана.
7. **Светодиоды (LED)**: Панелька с 5 диодами, которые загораются цветом акцента.

### 4.17. ↔️ Свайп недель (`ui/controls.js`)
- В настройках (Интерфейс) добавлен тумблер **«Свайп для смены недель»**.
- Если включен, горизонтальный свайп (`touchstart`/`touchend`) строго по элементу `.week-control` переключает недели.
- Защита от конфликта со скроллом: CSS-свойство `touch-action: pan-y;` на `.week-control` разрешает только вертикальный скролл, а горизонтальный перехватывается JS. Также в JS проверяется, что `deltaX > deltaY` и `deltaX > 50px`.

- Шрифт **Tsap-Tsarap** (`body.font-tsap`) имеет базовый размер **больше на 4-8px** (по сравнению с обычными шрифтами), так как его визуальные метрики (x-height) меньше. Теперь он читается так же комфортно, как и Minecraft.

### 4.21. 🛠 Скрытый Режим Отладки (DANGER ZONE)
**Что это:** Скрытая панель разработчика, которая не видна обычным пользователям.

**Как открыть:**
- Зайти в Настройки.
- 5 раз быстро кликнуть по тексту версии в самом низу (`TimeHub-Portal • v...`).
- Снизу плавно выедет красный блок «ОТЛАДКА (DANGER ZONE)».

**Возможности отладки:**
- **Машина времени:** Установка фейкового времени (часы/минуты). Таймер и расписание будут думать, что сейчас это время. (Реализовано через метод `state.getNow()`).
- **Принудительный день/неделя:** Мгновенный переход на нужный день и неделю.
- **Копировать State:** Выгружает `state.data` в буфер обмена (JSON).
- **Hard Reset:** Полная очистка `localStorage` и `sessionStorage` с перезагрузкой.
- **Стрик:** Кнопки «Сломать (38ч)» и «Убить (50ч)» для тестирования сгорания огонька.
- **Окружение:** Показывает текущий CACHE_NAME, платформу Telegram и размер экрана.

**⚠️ КАК ОТКЛЮЧИТЬ ОТЛАДКУ В РЕЛИЗЕ:**
В файле `assets/js/config.js` найди строку `ENABLE_DEBUG: true` и поменяй на `false`. После этого клики по версии перестанут открывать панель, а все обработчики отладки не будут инициализироваться.

**Особенности реализации:**
- Блок изначально скрыт через `style="display: none;"` и открывается только по JS (чтобы не появлялся сам по себе).
- Кнопка «Скрыть отладку» убирает класс `open`, ставит `display: none` и сбрасывает счетчик кликов.

### 4.22. 🎭 Стили Интерфейса (UI Styles) — v2.0
**Что это:** Слой поверх цветовых тем, который меняет геометрию, границы, тени и добавляет спецэффекты (сетки, сканлайны, рамки). **Крайне важно:** стили спроектированы так, чтобы **не перебивать** выбранную пользователем цветовую тему и шрифт. Они используют системные переменные (`var(--accent-color)`, `var(--text-main)` и т.д.).

**Доступные стили (выбираются в настройках):**
1. **Стекло (default)**: Базовый стиль с прозрачностью и размытием (backdrop-filter).
2. **Терминал (terminal)**: Прямые углы, моноширинный шрифт (если выбран), жесткие рамки `var(--accent-color)`, ASCII-скобки `[ ]` вокруг заголовков, фоновая сетка и сканлайны (эффект старых мониторов). Мигающий курсор в таймере.
3. **Брутализм (brutalism)**: Прямые углы, огромные рамки (3px), жесткие тени (`box-shadow: 4px 4px 0px var(--text-main)`). Кнопки при нажатии «вдавливаются».
4. **Nothing (nothing)**: Прямые углы, точечный паттерн на фоне (через `radial-gradient`), прозрачные карточки без размытия. Идеально сочетается с темой Nothing.

**Что было удалено в v2.0:**
- Стили Киберпанк, Синтвейв, Бумага, Neumorphism, Aero Y2K и Minecraft были удалены из-за перегруженности, плохой совместимости с цветовыми темами и багов.

**Техническая реализация:**
- В `config.js` добавлена настройка `uiStyle: 'default'`.
- В `themes.js` добавлена функция `applyStyle(styleName)`, которая вешает класс `style-...` на `body`.
- В `themes.css` прописаны CSS-классы для каждого стиля. Они меняют `border-radius`, `box-shadow`, `border` и добавляют псевдоэлементы `::before`/`::after`.
- В `ui/settings.js` добавлен блок кнопок для выбора стиля.

## 6. Ключевые модули — подробный разбор

### 6.1. `main.js` — Точка входа
- Инициализирует компоненты в строгом порядке.
- `applyBackground()` — применяет обои. `applyAllSettings()` — применяет всё с защитой от рекурсии (вырезает `_updatedAt` из сравнения).
- Слушает `tg.BackButton`, `focusin`/`focusout` (для `enableClosingConfirmation`).

### 6.2. `state.js` — Singleton
- `state.get(key)`, `state.set(key, value)`, `state.on(event, callback)`, `state.emit(event, data)`.
- **`state.getNow()`** — единая точка получения времени. Возвращает `new Date()`, если нет `debugTime`, или фейковое время из отладки.
- `state.determineWeek()` — вычисляет неделю от `SEMESTER_START_DATE` (26.10.2026).
- `state.initStreak()` — логика 36/48 часов.
- `state.reviveStreak()` — спасает огонь из статуса `dying`.
- `state.resetStreak()` — сбрасывает на 1 день.
- `state.restoreSettingsFromCloud()` — восстанавливает настройки при очистке кэша.

### 6.4. `themes.js` — Применение тем/шрифтов/стилей/масштаба
- `applyTheme(name)` — сбрасывает старые классы `theme-*` и ставит новый.
- `applyStyle(name)` — сбрасывает старые классы `style-*` и ставит новый.
- `applyFont(name)` — сбрасывает старые классы `font-*` и ставит новый.
- `applyTextScale(scale)` — меняет CSS-переменную `--text-scale`.
- `initThemes()` — вызывает все четыре функции при старте.

### 6.5. `data-manager.js` — Склейка данных (ДИНАМИЧЕСКИЕ ДАТЫ)
- `getDateForDay(week, day)` — вычисляет точную дату для выбранной недели и дня (отталкиваясь от 26 октября).
- `getLessonsForDay(week, day, group)` — получает базовое расписание, вычисляет дату, делает `fetch` к `data.json`, ищет замены по этой дате, применяет их, сортирует, применяет `customTimes`.

### 6.6. `data/schedule/index.js` — Агрегатор
- Читает `manifest.json`, импортирует все файлы, склеивает в `ALL_SCHEDULES`.

### 6.7. `ui/skeleton.js` — Скелетоны загрузки
- `renderScheduleSkeleton()` возвращает HTML с `.shimmer`.

### 6.8. `ui/notes.js` — Заметки и чек-лист
- **Авто-ресайз:** `autoResizeTextarea()` срабатывает на `input` и при загрузке, ограничивает высоту 400px.
- **Флаг `isLoaded`:** блокирует сохранение до загрузки облака.
- **Debounce:** 500 мс для текста.

### 6.9. `ui/settings.js` — Настройки
- Модалка в виде аккордеона (4 группы: Оформление, Обои, Интерфейс, Приложение).
- Внутри: горизонтальная карусель тем, сетки кнопок (включая **4 стиля UI**), тумблеры (включая «Свайп для смены недель»).
- QR-код: генерация через `esm.sh` с `ensureDarkEnough()`.
- **DANGER ZONE**: скрытый блок отладки (см. п. 4.21).

### 6.10. `ui/header.js` — Шапка и стрик
- Меню огонька. Кнопки `reviveStreak` и `resetStreak` показываются в зависимости от статуса.
- Секретки: 5 кликов → `matrix`, 10 кликов → `nothing`.

### 6.11. `builder.js` — Конструктор
- 3 режима (`schedule`, `substitution`, `consultation`).
- Слияние консультаций и замен при генерации.
- Сравнение замен с базовым расписанием (выдает только отличия).
- Автоподстановка работает везде.

### 6.12. `pwa.js` — Service Worker и установка
- `initPWA()`: `beforeinstallprompt`, `updatefound`, `controllerchange`.
- `promptInstall()` — вызывает `deferredPrompt`.

### 6.13. `sw.js` — Service Worker
- Network First. Игнорирует `telegram.org`, `open-meteo.com`, `wttr.in`, `esm.sh`, `fonts.googleapis.com`, `fonts.gstatic.com`.

### 6.14. `ui/timer.js` — Таймер пар
- **Перемены:** если сейчас перемена между парами, показывает название и кабинет следующей пары.
- **Пара:** делит пару (95 минут) на 2 половины по 45 минут с переменой 5 минут посередине.
- **Кабинет:** во время пары рядом с названием предмета отображается кабинет (`📍 ...`).
- **Полноэкранный режим:** `position: fixed`, локальные частицы Canvas (`#timer-particles`).
- **После пар / до пар:** считает время до следующего учебного дня.

## 12. Известные баги и их фиксы

| Симптом | Причина | Решение |
|---------|---------|---------|
| Старая версия сайта | Не обновлён `CACHE_NAME` | Git-хук делает это автоматически |

| Base64-обои не синхронизируются | Лимит TG (4096) | Синхронизируются только URL-обои |
| Таймер вылезает за экран | `transform: scale()` | Использовать `clamp()` и `vw` |
| Ошибка `Script error` в TG | Внутренняя ошибка WebView | Игнорируется в `main.js` |
| Стрик не растёт | `lastVisit` не совпадает | Проверить `initStreak()` |
| Замены не отображаются | Ошибка в `data.json` | Проверить JSON и дату |
| Чек-лист с полосой прокрутки | `max-height` в CSS | Убрать (сделано) |
| QR-код не сканируется | Длинная ссылка | Короткая ссылка бота |
| Огонек перекрывается | Нет `z-index` у шапки | Проверить `z-index: 100` |
| `state.getNow is not a function` | Метода нет | Добавить в `state.js` (сделано) |
| Кнопка генерации мертва | Ошибка в скрипте | Проверить консоль (F12) |
| Консультации не сохраняются | Генерировался JSON вместо JS | Перейти на `consultations.js` |
| Таймер не на весь экран | Баг `position: fixed` с blur | Отключить `backdrop-filter` в `.fullscreen` |
| Карточки наезжают на 338px | `min-width` без `0` у `.lesson-info` | Добавить `min-width: 0` и медиа-запросы |
| Переключатель перекрывает контент | Нет `padding-bottom` у `#app` | Добавить отступы в CSS |
| Меню дней улетает за края | `translate` по дуге (rotate) | Использовать координаты `--x`/`--y` (веер) |
| Настройки не масштабируются | Жесткие `px` вместо `calc` | Заменить на `calc(X * var(--text-scale))` |
| Tsap-Tsarap слишком мелкий | Меньший x-height шрифта | Увеличить базовый `font-size` на 4-8px |
| Свайп недель конфликтует со скроллом | Нет `touch-action` | Добавить `touch-action: pan-y;` на `.week-control` |
| Отладка открыта по умолчанию | Класс `open` остался в DOM | Скрывать через `display: none` + удалять класс |
| Кнопка "Скрыть отладку" не работает | Ошибка `updateEnvInfo is not defined` | Вынести функцию из блока `if` |
| Нет кабинета в таймере | Терялся при рендере текущей пары | Добавить `lesson.room` в `subjectHTML` |
| Стили UI перебивают цвета/шрифты | Хардкод цветов и шрифтов в `style-...` | Использовать только `var(--accent-color)` и наследование шрифтов |
